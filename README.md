# Zero To Expert 🚀

A structured roadmap documenting my journey from learning JavaScript fundamentals to becoming a professional Backend Developer using Node.js and modern backend technologies.

## About

This repository contains projects, exercises, notes, and practical implementations created while following a complete Backend Developer learning path.

The objective is not only to learn syntax, but also to understand software engineering principles, backend architecture, security, testing, deployment, and production-ready application development.

# Learning Roadmap

### Goal

Understand programming fundamentals and develop problem-solving skills.

### Topics

* Data Types
* Operators
* Conditional Statements (`if`, `else`)
* Loops (`for`, `while`)
* Functions
* Arrays
* Objects
* Scope
* Basic Error Handling
* Debugging with `console.log`

### Projects

* Calculator CLI
* Guess The Number
